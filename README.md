# Photoshop Toolkit

Набор скриптов, операций и пресетов Photoshop для съёмочного конвейера:
от отбора RAW по звёздам до сборки карусели для Instagram и нарезки её
на отдельные слайды.

Писалось под свой рабочий процесс, но всё настраивается блоком констант
в начале каждого файла — переименовать папки, поменять формат или
размеры можно, не трогая логику.

## Состав

```
Action/       наборы операций Photoshop (.atn)
Droplets/     дроплеты — в репозиторий не входят, см. ниже
Other/        пресеты рабочей среды и batch-сортировщик
Scripts/      скрипты ExtendScript (.jsx)
tools/        atn_tool.py — чтение и правка .atn вне Photoshop
GUIDE.md      подробное описание каждого скрипта
```

## Скрипты

| Файл | Что делает |
|---|---|
| `RawToPSD.jsx` | Отбирает RAW по оценке в звёздах и конвертирует в PSD, раскладывая по папкам проекта |
| `Slides.jsx` | Создаёт документ-ленту из 10 или 20 слайдов с направляющими и раскладывает по нему фотографии |
| `Import_into_Slides.jsx` | Заполняет снимками уже готовый документ-ленту |
| `Cut.jsx` | Режет ленту на отдельные JPEG по слайдам |
| `Stripes.jsx` | Делит выделение на горизонтальные полосы или вертикальные колонки с градиентом серого |
| `Stroke_auto.jsx` | Белая внутренняя обводка по выделению, толщина в процентах от его размера |
| `Save_near_PSD.jsx` | Быстрое сохранение JPG рядом с PSD, без вопросов |
| `Save_options.jsx` | Сохранение с выбором: папка, формат JPG или TIFF, обводка, качество, перезапись |

Подробности по каждому — в [GUIDE.md](GUIDE.md).

## Установка

1. Скопируйте `Scripts/` туда, откуда Photoshop их увидит:
   `C:\Program Files\Adobe\Adobe Photoshop <версия>\Presets\Scripts\`
   Перезапустите Photoshop — скрипты появятся в `Файл → Сценарии`.
   Можно и не копировать: `Файл → Сценарии → Обзор…` запускает `.jsx`
   из любого места.
2. Наборы операций из `Action/` подключаются в палитре `Операции`
   через `Загрузить операции`.
3. Пресеты из `Other/`: `MyWorkPlace.psw` — раскладка палитр,
   `ToolBar.tbr` — панель инструментов.
4. Горячие клавиши: `Редактирование → Клавиатурные сокращения →
   Меню программы → Файл → Сценарии`.

### Важно про пути в операциях

Операция, запускающая скрипт, хранит внутри **абсолютный путь** к `.jsx`.
В наборах из `Action/` пути указывают на

```
C:\Program Files\Adobe\Adobe Photoshop 2025\Presets\Scripts\
```

Если у вас другая версия Photoshop или скрипты лежат в другом месте,
перепишите пути одной командой:

```
python tools/atn_tool.py repath Action/Export.atn Export_my.atn "D:\Мои скрипты"
```

Проверить, что все пути живы, можно командой `check`.

## Структура папок проекта

Скрипты рассчитаны на такую раскладку съёмки, её создаёт
`Other/Sort_Photo_Folders.bat`:

```
26_09_20_Shooting/
    1. JPG EDITED/     готовые JPG
    2. PSD/            обработка
    3. RAW TO EDIT/    отобранные RAW
    4. JPG ORG/        внутрикамерные JPG
    5. RAW/            весь материал
    6. COLLAGE/        карусели
```

`RawToPSD.jsx` знает про связку `3. RAW TO EDIT → 2. PSD`,
`Save_options.jsx` — про `2. PSD → 1. JPG EDITED`. Имена папок задаются
константами в начале файлов.

## Дроплеты

`Droplets/` в репозиторий не входит. Дроплет Photoshop — это `.exe`,
жёстко привязанный к конкретной версии программы и к записанной
операции: на чужой машине он бесполезен, а неподписанный исполняемый
файл в репозитории справедливо настораживает антивирусы.

Свой собирается за минуту: `Файл → Автоматизация → Создать дроплет`,
указать набор и операцию, поставить галки «Переопределить команды
Открыть», «Запретить диалоги параметров открытия файлов», «Запретить
цветовые профили» и обязательно «Записать ошибки в файл».

## Требования

Photoshop CS6 или новее, проверялось на 2025. Для `tools/atn_tool.py`
нужен Python 3.8+ без сторонних библиотек.
